The transverse-field Ising model ​

To follow this example you need the following packages:

julia
using MPSKit, TensorKit, CairoMakie
using .ExampleModels
using TensorKitTensors.SpinOperators: σᶻ

For reproducibility of this page, we fix the seed of the random number generator:

julia
using Random
Random.seed!(1234);

We fix a finite chain length L, a bond dimension D and the set of field values to scan. D is kept modest so the example runs quickly; increasing it sharpens the results in the thermodynamic limit.

julia
L = 16
D = 8
g_values = 0.1:0.1:2.0

Order parameter ​

We compute the order parameter at every field value, both on a finite chain and in the thermodynamic limit.

For the finite chain we use an open chain of L sites and optimize with DMRG. We average over the sites and take the absolute value, since a symmetry-broken state can have either sign.

julia
ψ₀_finite = FiniteMPS(L, ℂ^2, ℂ^D)
M_finite = map(g_values) do g
    H = transverse_field_ising(; L, g)
    ψ, envs, info = find_groundstate(ψ₀_finite, H, DMRG(; verbosity = 0))
    return abs(sum(i -> expectation_value(ψ, i => σᶻ()), 1:L)) / L
end

In the thermodynamic limit, we drop the length L to build the Hamiltonian on the infinite chain, and optimize an InfiniteMPS with VUMPS. We keep the optimized states, since we will reuse them for the entropy and the correlation length below. On the ordered side, the infinite state settles into one of the two symmetry-broken ground states, so we again take the absolute value.

julia
ψ₀_infinite = InfiniteMPS(ℂ^2, ℂ^D)
states_infinite = map(g_values) do g
    H = transverse_field_ising(; g)
    ψ, envs, info = find_groundstate(ψ₀_infinite, H, VUMPS(; verbosity = 0))
    return ψ
end
M_infinite = [abs(expectation_value(ψ, 1 => σᶻ())) for ψ in states_infinite]

The two calculations agree in the disordered phase, but not in the ordered one. The infinite state stays ordered up to   and then collapses, locating the critical point. On the finite chain, the magnetization vanishes well before  . The exact ground state of a finite chain is the symmetric superposition of the two ordered states, which only needs a small bond dimension, so DMRG readily finds it. Spontaneous symmetry breaking only happens in the thermodynamic limit, which is why the order parameter is best measured there.

Entanglement entropy ​

At a critical point correlations become long-ranged, and the ground state is more entangled than deep in either phase. For an InfiniteMPS, entropy returns the entanglement entropy of every bond in the unit cell, which here contains a single site.

julia
S_infinite = [real(only(entropy(ψ))) for ψ in states_infinite]

fig, ax, _ = scatter(g_values, S_infinite; axis = (; xlabel = "g", ylabel = "S"))
vlines!(ax, [1.0]; color = :gray, linestyle = :dash)
fig

The entropy peaks near  , the entanglement signature of the phase transition.

Correlation length ​

Finally, the correlation length is extracted from the transfer matrix spectrum of the infinite state, and has no finite-chain analogue. correlation_length returns one value per symmetry sector, and without symmetries there is only the trivial one. It grows towards the critical point, so we plot it on a logarithmic scale.

julia
ξ_infinite = [only(values(correlation_length(ψ))) for ψ in states_infinite]

fig, ax, _ = scatter(g_values, ξ_infinite; axis = (; xlabel = "g", ylabel = "ξ", yscale = log10))
vlines!(ax, [1.0]; color = :gray, linestyle = :dash)
fig

The correlation length peaks near   as well. At the critical point it should diverge, but an MPS with finite bond dimension D can only capture correlations up to a finite length, so the peak grows as D is increased. The critical point itself is studied in more detail in the Ising CFT example, which matches its excitation spectrum to the predictions of conformal field theory.
